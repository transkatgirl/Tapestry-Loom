## Tapestry Weave

This crate implements [Tapestry Loom](https://github.com/transkatgirl/Tapestry-Loom)'s document format, which is built on top of the [universal-weave](https://crates.io/crates/universal-weave) crate.

Unlike Tapestry Loom (which is licensed under AGPLv3), tapestry-weave is licensed under the [Unlicense](./LICENSE).

This library is a rust crate, which can be included in your project through the use of git submodules. In the future, once the API has been stabilized and the code has been throughly tested, this crate will be published to crates.io.
